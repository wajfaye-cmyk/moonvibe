# Security

Please **do not** report security problems in public issues. Use **Security → Report a vulnerability** on this
repository instead; only the maintainers can read those reports.

Worth reporting, for example:

- a way to change another player's cosmetics or cape,
- a problem with the sign-in handshake between launcher, cosmetics server and Mojang,
- a way to upload harmful files through the custom cape upload,
- anything that could leak a player's Minecraft or Microsoft token.

If you run your own cosmetics server, keep it up to date with `npm run deploy` in the `backend` folder after pulling
new changes.
